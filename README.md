# DailyChunk

**Big downloads. Small daily chunks.**

DailyChunk is a free, open source download manager for Android, built for people with limited or metered mobile data.

Got a 4 GB file to download but only 100 MB of spare data a day? Paste the link, tell DailyChunk how much it's allowed to download each cycle, and walk away. It downloads your allowance, stops automatically, waits, and picks up right where it left off — every day, until the file is complete. No manual restarting, no babysitting, no wasted data.

---

## Why DailyChunk

- 📶 **Works with limited data plans** — set a daily (or hourly) download allowance and DailyChunk respects it exactly
- ⏸️ **Pauses and resumes automatically** — no need to remember to restart anything
- 🔁 **Resumes from where it stopped** — even after a cycle wait, a phone restart, or losing signal
- 📡 **Waits for the internet, not fails on it** — if a scheduled download starts while you're offline, it simply waits until you're back online instead of erroring out
- 🔋 **Runs reliably in the background** — designed to keep working even when the app isn't open
- 🎨 **Clean, modern, and simple** — no clutter, no confusing settings, no ads
- 🌗 **Light, dark, or system theme**
- 🔒 **100% free and open source** — no trackers, no analytics, no hidden data collection, ever

---

## How it works

1. **Paste a download link.**
2. **Set your limits** — how much to download per cycle (even fractional, like 3.5 MB) and how often (minutes or hours).
3. **Choose when to start** — right away, or wait until the first cycle naturally comes around.
4. **Let it run.** DailyChunk downloads your set amount, stops on its own, and schedules the next round.
5. **Get notified** when it's done. Your file is saved in your phone's regular **Download → Daily Chunk** folder, just like any other download — open it, share it, or find it with any file manager.

That's it. Set it up once, forget about it, and check back whenever you like.

---

## Features

- Add and manage multiple downloads at once, each with its own schedule
- See live progress, current cycle usage, download speed, and time until the next cycle
- Pause and resume manually, any time
- A simple built-in Files tab to view, open, share, rename, or delete anything DailyChunk has downloaded
- A History tab to see everything you've downloaded, failed, or cancelled
- Adjustable settings: default cycle size, Wi-Fi-only mode, notifications, theme, and how many downloads can run at once (including any custom number you choose)
- Friendly error messages instead of technical jargon when something goes wrong, with automatic retries for temporary issues

---

## Privacy

DailyChunk doesn't collect, store, or transmit any personal data. There are no analytics libraries, no ad networks, and no third-party tracking of any kind built into this app. The only network requests it makes are the direct downloads you ask it to perform.
